# 라벨 모드 (이미지 보기 안, 계획_라벨링 1b)

이미지 보기(`../viewer/NdeViewer.tsx`)에 붙는 결함 라벨링 화면입니다. 도구막대 **'라벨'** 또는 **L** 키로 켜고 끕니다.

- 끄면(보통 모드) 영상 위 덮개·S-scan 확대·라벨 조작이 모두 빠지고, 그림은 라벨 모드를 만들기 전과 바이트 단위로 같습니다.
- 켜면 영상 위 라벨 덮개, S-scan 확대(휠·눈금자 끌기·더블클릭·Z), 도구별 조작, 오른쪽 라벨 패널 열이 생깁니다.
- 덮개는 영상 캔버스 위에 겹친 그림 전용 캔버스(`.vplot__overlay`, 포인터를 받지 않음)에 그립니다 — 덮개·시간 커서만 바뀔 때 영상을 다시 칠하지 않습니다.
  덮개 객체는 뷰마다 내용이 같으면 같은 객체(`NdeViewer` `stableOv`)라 덮개 캔버스도 다시 그리지 않습니다.
- S-scan 확대는 '조정됨'·'파일값으로'에 넣지 않고 도구막대에 따로 '확대' 표시를 둡니다(Z 로 풂). 도구막대는 넘치면 줄을 바꿉니다(1280 폭 가로 스크롤 없음).
- 라벨 모드에서는 상단바 '파일 가져오기'를 보조 버튼 모양으로 바꿔 화면의 파란 버튼이 패널 저장 하나가 되게 합니다(`labeling.css`).
- 검수 '영상으로 보기'로 열면(`NdeViewer` `target`·`compare`) 그 기록 칸으로 가서 라벨 패널 자리에 **두 세트 비교 보기**(`ComparePanel.tsx`, 읽기 전용 — A 기록 자홍, B 기록 주황)를 띄웁니다. 뒤로 가기 글자는 '라벨 관리로'.

## 전문가가 파일 하나를 라벨하는 순서 (패널)

1. **세트** (맨 위 한 줄): 지금 라벨러 · 지침서 버전 · 판독 단계. 처음에는 이 파일에 지금 라벨러가 마지막으로 쓴 세트, 없으면 `v1 · 블라인드`. '바꾸기'로 고릅니다. 라벨러가 없으면 라벨 관리로 안내하고(찍은 점은 남음), 2인 독립 모드면 다른 라벨러 세트와 앱 제안을 숨긴다고 적습니다. 세트를 정하면 그 세트의 기록·검토 구간·관측 행을 불러옵니다.
   - **라벨러가 바뀌면**(패널에서든 라벨 관리에서든) 앞 라벨러의 초안(점·사각형·R·검토 구간)·되돌리기 이력·고치던 기록·보여 준 제안을 비웁니다(패널 상태 `owner`). 2인 독립 모드에서 남의 작업을 보거나 내 세트로 저장하지 않게.
   - **블라인드 제출(잠금)**: 블라인드 판독을 마치면 제출합니다. 제출한 세트는 앱에서 고칠 수 없습니다(서비스가 `CONFLICT`, 패널은 보기만). 풀 때는 이유가 필요합니다(기록에 남음).
   - **설계값 대조 시작**: 블라인드 세트를 제출하고, 기록·검토 구간·확인한 관측을 새 UUID 로 복사한 '설계값 대조' 세트를 만듭니다(지침서 2.4·15절 — 설계값을 본 뒤에는 사본에서만 고침). 대조 단계에서는 물리 결함 ID 를 이 파일 시편의 설계값 목록에서 고릅니다.
   - **확정** 세트는 검수 화면(Level III 확정)에서만 만들고 고칩니다 — 패널에서는 '확정 (보기만)'.
2. **새 기록** (두 도구 가운데 하나, 머리 도구 1~3 과 같은 상태)
   - ① 단면: 높이 입력 방식(상하 팁 / 팁 + 표면 / 노정 시간 / −6 dB(참고) / 측정 불가)에 따라 찍을 점 목록이 정해집니다. 목록 칸을 누르면 그 점을 찍을 차례가 되고, 찍으면 다음 빈 칸으로 넘어갑니다. **N** = 지금 칸 ± 2 칸·± 2 빔의 게이트 최대 칸을 '최대 진폭' 점으로(그 칸으로 커서를 옮김). S-scan 을 눌러 찍는 '최대 진폭' 점은 ± 1 빔·± 1.5 mm 안 국소 최대로 붙습니다. **T** = A-scan 시간 커서 깊이를 지금 점으로(팁 피크 깊이).
     '에코 범위(사각형)'는 **결함이면 필수**(지침서 6.4) — **'에코 범위 자동'** 이 최대 진폭 칸에서 평가 기준 이상으로 이어진 칸 덩어리로 채웁니다(전문가가 확인·다시 그림). 레그 경계를 넘는 사각형은 최대 진폭 점의 레그 안으로 자르고, 부채꼴 밖 모서리는 안으로 당깁니다.
   - ② 길이: 기준 커서 **R**(시작) → 현재 커서(끝), 또는 길이 도구(3)로 C/B-scan 끌기 → **'이 길이로'**. 그 뒤에만 앱 제안을 비교값으로 보여 줍니다(2인 독립 모드면 숨김). 제안은 **같은 단면이면 한 번만** 계산해 고정합니다(다시 눌러도 처음 잰 값·제안이 바뀌지 않음). 제안은 기록과 같은 측정법·관 외경으로 냅니다. 포화·동적 범위 6 dB 미만이면 '제안 불가'와 이유. '제안값으로 바꾸기'를 누르면 수락으로 남습니다. 길이를 잰 빔이 최대 진폭 빔이 아니면 '최대 진폭 빔으로 R 맞추기'.
   - ③ 속성: 구분 · 결함 종류 · 존재 확신도(미리 채우지 않음 — 꼭 고름) · 메모. 나머지(종류 확신도·판정 특성·일렬 체적·표면·점 같은 지시·위치·좌우·덮개 없음·길이 측정법(기타면 문턱 %FSH)·관 외경·설계값 봤음·시편 미리 앎·AI 개발 참여·물리 결함 ID)는 '세부 칸'. 형상 불완전 세부도 미리 채우지 않습니다.
   - 저장(파란 버튼 하나, 패널 아래에 붙어 늘 보임, **Ctrl/Cmd+Enter**): 막는 문제는 빨강, 볼 것은 파랑 빈 원. 저장하면 ① 단면으로 올라갑니다. 처음 저장할 때 고정 지시 번호(`A1`…, 대조 단계에서 더한 것은 `C1`…)를 매깁니다.
     최대 진폭이 평가 기준 미만이면 경고와 '기준 미만 지시로 바꾸기'(검토 구간 초안으로, 지침서 5.2).
3. **검토 구간** (지침서 순서대로 형상 에코 후보가 위): 검토 구간 도구(4)로 C/B-scan 을 끌거나 '전체 구간으로' → 종류(검토 완료 · 품질 불량(사유 필수) · 기준 미만 지시) → '구간 저장'. 검토 완료는 지금 C-scan 게이트의 펼친 깊이·레그 범위를 함께 저장합니다(지금 게이트가 파일 게이트와 다르면 알림). 기록의 위치·길이·구분이 바뀌거나 결함 기록을 더해 자동으로 풀린 구간은 다시 본 뒤 '다시 검토 완료로'(풀린 구간을 모두 되돌리면 '자동으로 풀렸습니다' 알림이 닫힘). 저장한 구간 '지우기'는 한 줄 확인을 거칩니다(포커스는 '취소', 취소하면 '지우기' 단추로 — 지시 표 '지움 표시'와 같은 방식).
4. **지시 표**: 이 세트 기록. 번호 = 고정 지시 번호(엑셀 '지시 번호' 또는 `A1`…) — 검수 표·CSV 와 같은 이름. 행 = 그 기록의 최대 진폭 스캔·빔으로 커서 이동(↑/↓ 로도 — 그룹·최대 진폭이 빈 엑셀 기록은 스냅샷 커서, 그것도 없으면 지금 그룹의 기록 스캔 구간 가운데로 가고 '그룹 모름' 을 보임, `record.ts` `gotoTargetOf`), 두 번 누름·Enter = 고치기. 고른 기록 아래에 표시(재확인 필요·좌표 규칙 바뀜·대조 전·엑셀/앱 제안 승인), 고치기, 그때 화면으로(이득·게이트·색표 스냅샷), 지움 표시, **관측 표**(그룹 × 레그 계산 상태를 보임/약함/안 보임으로 확인 — 확인 행 저장, 그룹마다 '이 그룹 확인', 값 = 최대 %FSH).
5. **형상 에코 후보** (펼친 동안 계산·영상에 청록 띠): 승인(형상 에코 기록, 앱 제안 승인) · 고침(스캔 구간·세부) · 거절(이 세션 목록에서 뺌). 블라인드 판독(판독 단계 블라인드·2인 독립 모드)에서는 '띠보다 센 곳'·'기록 기준 넘는 구간'·최대 진폭 단서를 숨깁니다(띠 위 결함 위치를 앱이 미리 알려 주지 않게).
6. **장면 세 상태 미리보기** (켜면): 이 세트로 계산한 장면 상태를 C-scan 첫 빔 줄 띠와 S-scan 객체 상자로.
7. **단축키** 표.

작업 이벤트(판독시간 근거, `workSession.ts` — 뷰어가 들고 있어 라벨 모드를 껐다 켜도 이어짐): 세트가 정해진 때(이 파일에 지금 라벨러 세트가 이미 있으면 뷰어를 연 때, 없으면 패널이 세트를 정한 때)부터 뷰어를 닫을 때까지 파일 열기·닫기 한 세션, 기록 생성·수정·삭제, 검토 완료, 라벨 추가 작업('label-extra': 형상 에코 승인·검토 구간 저장·라벨 모드의 게이트 바꾸기), 5분 넘게 입력(키·마우스·휠)이 없었던 구간(다시 입력하거나 닫을 때 그 구간 전체를 '쉼'으로). `labels:appendWorkEvent`.

고치기: 고치기를 시작할 때의 기록(버전)으로 저장합니다. 그사이 다른 곳에서 바뀌었으면 `CONFLICT` — 초안은 두고 '다시 열기'로 새 내용을 불러오기 전까지 저장하지 않습니다(다른 곳의 변경을 덮지 않게). 고치던 기록이 없어졌으면 알리고 '새 기록으로 저장하기'·'그만두기'. 점·사각형을 바꾸지 않았으면 기록의 화면 스냅샷을 그대로 둡니다(새 기록의 스냅샷은 첫 점을 찍은 때의 화면).

## 조작 (도구 = 1~4 키 또는 패널 머리의 도구 묶음)

| 도구 | S-scan | C/B-scan | 그 밖 |
|---|---|---|---|
| 1 점 | 클릭 = 점 찍기(깊이 포함, 그 빔이 현재 빔), 끌기 = 사각형 | 보통처럼 커서 고르기 | |
| 2 사각형 | 끌기 = 사각형, 클릭 = 빔 고르기 | 보통처럼 | |
| 3 길이 | 보통처럼(빔 고르기·게이트 점선 끌기) | 끌기 = 누른 곳이 기준 커서 R, 놓은 곳이 현재 커서 → 측정값 줄 S(m−r) | R = 지금 커서를 R 로, Shift+R = R 지움 |
| 4 검토 구간 | 보통처럼 | 끌기 = 스캔 구간 | |

모든 도구에서: A-scan 클릭·끌기 = 시간(깊이) 커서, N = 지금 칸 ± 2 칸·± 2 빔의 게이트 최대를 '최대 진폭' 점으로, T = 시간 커서를 점으로, Delete = 고른 점 지우기(패널 안 포커스에서는 듣지 않음), Esc = 끄는 중 취소·선택 해제, Ctrl/Cmd+Enter = 기록 저장. Ctrl/Cmd+Z 는 후처리(범위·게이트·이득)와 라벨 초안 가운데 마지막에 고친 쪽부터 되돌립니다(보통 모드는 지금처럼 후처리만). 입력란(입력·선택·글상자)에 포커스가 있으면 뷰어 키는 듣지 않습니다. 라디오 묶음(도구·작업)은 화살표만 스스로 쓰고, 마우스로 누르면 포커스가 영상으로 돌아와 ←/→·R·N 이 바로 듣습니다. L 로 끄면 포커스가 영상에 남습니다. 그룹이 여럿이면 패널의 '○○만 보기'로 한 그룹만 크게.

## OmniPC 조사 반영 (2026-10-07, `../../../../../OmniPC_조사/조사_보고.md` 6절)

근거는 공개 MXU 설명서·사용자 파일·우리 데이터 파일·OmniPC 캡처뿐입니다(설치본은 보지 않음).

- **길이 이름 = S(m−r)** (N1). OmniPC 측정값의 S 는 스캔축, U 는 초음파축(깊이·음로)입니다. 앱의 R → 현재 커서 길이는 스캔축 거리라 측정값 줄·패널 '② 길이'·도구 설명·단축키 표 모두 S(m−r) 로 부릅니다(계산·부호는 그대로 — 설명서의 m − r). OmniPC 에서 높이(두 팁 깊이 차)는 U(m−r) 입니다.
- **A-scan 기준선** (X3, `../viewer/levelLines.ts`): 라벨 모드에서는 기본으로 A-scan 진폭 축에 기록 기준(Ref −8 dB)·평가 기준(Ref −14 dB) 두 세로 점선을 그립니다(t < 8 이면 −12 dB 하나). 값은 `levels.ts`, 화면 이득 Δ 만큼 옮깁니다. 오른쪽 위 꼬리표 'Ref 대조 전'(TCG 없는 그룹은 '· TCG 없음'). 'Ref' 라는 이름의 선(X3 159.6 %)은 그리지 않고 Ref 값은 조정 패널 툴팁 숫자로만 둡니다(2026-10-07 검토 — OmniPC 의 'Ref.' 80 % 선과 다른 높이에 보여 헷갈리므로). 두 선은 OmniPC 의 빨간 TCG 선(80 %)과 다른 선입니다 — OmniPC 화면에서는 그 선에 닿은 신호가 Ref −6 dB. 조정 패널 '색표' → '색 범위' 의 'A-scan 기준선'으로 모드마다 켜고 끕니다(이 세션 동안 기억). 기준선은 따로 겹친 캔버스(`.vplot__levels`)라 영상 캔버스는 그대로입니다.
- **신호 줄의 Ref 근거** (X2): 신호 그룹이 TCG 근거가 없으면(`ViewerGroup.refBasis = 'single-depth'`) '최대 진폭' 줄에 'Ref 근거 약함(TCG 없음)', 기준 이득이 없으면 'Ref 없음'. 기록 칸(`SignalInfo`)은 바꾸지 않습니다(`recordText.ts` `signalText`).
- **이전·다음 파일** (X9): 뷰어 도구막대 '◀ 이전 · 다음 ▶'·키 `[`·`]` = 같은 플랜·시편 파일을 이름 순서로. 라벨 모드에서 넘기면 다음 파일도 라벨 모드이고, 초안·도구·패널(라벨 세션)·후처리는 파일마다 남아 돌아오면 이어집니다. 작업 이벤트는 앞 파일 '파일 닫기' → 다음 파일 '파일 열기'(뷰어를 닫고 여는 것과 같음).

## 기록 만들기 규칙 (`record.ts`)

- 앵커 = 찍은 점마다 (그룹, 스캔 칸, 빔 실수, 샘플 실수) + 좌표 규칙 버전 + 찍을 때 대조 여부, mm = V·접은 깊이·레그. 파생 위치 = `derivedFromPoints`(좌표 규칙이 바뀌어 다시 계산할 때와 같은 규칙): 스캔 = 길이 시작·끝, V = 사각형 → 모든 점, 깊이 = −6 dB 점 → 사각형 → 모든 점.
- **길이 시작·끝 점**의 앵커 빔·샘플·V·깊이는 단면 기준점(같은 그룹 최대 진폭 점 → 첫 단면 점 → R 칸·빔의 게이트 최대)과 같게 둡니다. 그래야 '모든 점'으로 V·깊이를 낼 때 길이 점이 단면 밖 V 를 끌어오지 않습니다. 길이를 잰 빔(C-scan 한 행)은 `measuredBeam` → `length.beam`.
- 길이 점은 저장 직전 지금 단면 기준점으로 다시 맞춥니다(`realignLengthPoints` — 길이를 정한 뒤 최대 진폭 점을 옮겨도 옛 V·깊이가 남지 않게).
- 높이: 상하 팁·노정 시간 = 아래 − 위 (실제 깊이), 팁 + 표면 = 팁과 가까운 면(0 또는 t)의 차(루트 연결 = t − 위 팁, 윗면 연결 = 아래 팁), −6 dB = 두 점 차(참고), 측정 불가 = 값 없음. 점이 모자라거나 **아래 점이 위 점보다 얕으면**(짝수 레그는 화면 위아래가 반대) 저장을 막습니다. 두 점의 레그가 다르면 경고하고, 경계 ± 0.3 mm 안의 점은 면으로 붙입니다.
- 신호: **단면 둘레 최대**(`regionPeakOf` — 단면 점·사각형의 빔 ± 2 · 펼친 깊이 ± 1.5 mm, 같은 그룹 길이 구간(없으면 단면 칸 ± 2)의 원값 최대, 파일 이득 0 dB)와 `levels.ts`(Ref 대비 dB, 평가·기록 기준, 대조 전이라 `refDbVerified = false`). 찍은 최대 진폭 점이 둘레 최대보다 6 dB 넘게 낮으면 경고. 진폭을 읽는 중이면 새 결함은 저장을 막고, 고치기는 고치기 전 신호를 둡니다. 정수 빔 점(끝 빔 선 위 N 점)은 그 빔 A-scan 으로 읽습니다. 포화 허용은 derive 규칙과 같은 값.
- 길이: t ≥ 8 평가 기준 초과 구간(문턱 = 평가 기준 %FSH), t < 8 6 dB 강하 + 곡률 보정(외경을 적으면 l_c, 보정 전 l_s), 기타 = 적은 문턱 %FSH.
- 제안 기록: 보여 준 제안만(길이·시작·끝 세 줄, 수정량 = 최종 − 제안, 같으면 수락 — '길이' 줄의 최종은 기록 길이(곡률 보정 뒤)). 제안 불가였으면 한 줄. 2인 독립 모드·전문가가 재기 전 제안은 남기지 않습니다(같은 규칙 버전이면 나중에 같은 값으로 다시 계산됨).
- 엑셀 기록에 점을 찍어 앵커 기록으로 바꿀 때 다시 재지 않은 엑셀 길이·높이는 그대로 두고 알립니다.
- 대조·확정 단계는 늘 '설계값 봤음'. 형상 에코·형상 불완전은 결함 칸(종류·높이·표면·점)을 비우고 세부를 둡니다. 저장 전에 `validateIndicationRecord` 로 검사합니다.
- 고치기: 기록 → 초안(좌표 규칙이 바뀐 기록은 앵커에서 다시 계산한 위치) → 기록. 버전은 그대로라 그사이 다른 곳에서 바뀌었으면 저장이 `CONFLICT` 이고 다시 읽습니다. 엑셀 기록(앵커 없음)은 새 점을 찍지 않으면 위치·길이·신호를 두고 속성만 고칩니다. 다시 저장하면 '재확인 필요'가 지워집니다.
- 앱이 승인한 형상 에코는 `echoCandidateRecordFields` 그대로라 앵커 없이 mm (coordSource `imported-mm`, 표에는 '앱 제안 승인').

## OPD 파일 (MX2 .opd, 구조를 따라 읽음)

라벨 기록·앵커·JSON 왕복은 NDE 와 똑같이 된다(기록은 sha256 으로 파일에 붙고, 앵커는 그룹·스캔 칸·빔·샘플). 다만 OPD 그룹은 모두 OmniPC 대조 전(`verified = false`)이라 자동 변환·학습 내보내기는 막힌다. 패널은 대조 전 경고에 '(OPD)' 를 붙이고, 파일에서 스캔 축 동기 방식을 알 수 없어(`scanSync: 'unknown'`) 스캔 mm 가 명목값(칸 번호 × 간격)이라는 경고를 더한다. 진폭 눈금이 추정(`ampScale.estimated`, raw 255 = 250 %)인 그룹의 최대 진폭에는 '(추정 눈금)' 을 붙인다. 계산(`analysis.ts`)은 그룹의 형식 이유(`blockReason`)를 derive 에 넘겨 학습 내보내기와 같은 판정을 한다. 최대 진폭 %(추정 눈금)와 스큐 270 의 V(출사점 부호 추정)는 8단계 대조 뒤 바뀔 수 있어 패널이 그렇게 알리고, 새 기록의 화면 스냅샷(불투명 JSON)에 `formatSource` { 형식, 읽기 규칙, 진폭 눈금, V 부호 추정 } 를 남긴다(NDE 스냅샷에는 칸이 없어 그대로). 지시 표는 OPD 그룹 기록에 '추정 값', 두께 칸이 의심스러운 파일(PL2386x)에 '두께 확인' 표시를 붙인다(`record.ts` `recordFlags`). 앵커가 있어 눈금·부호가 확정되면 다시 계산할 수 있다.

## 덮개 좌표 (뷰 축 단위)

| 뷰 | x | y |
|---|---|---|
| S-scan (그룹마다) | V mm (용접 중심선 기준) | 펼친 깊이 mm |
| C-scan (그룹마다) | 스캔 U mm | 빔 번호 (실수, 0부터 · 칸 b = [b − ½, b + ½]) |
| B-scan (활성 그룹·현재 빔) | 스캔 U mm | 펼친 깊이 mm |
| A-scan (활성 그룹·현재 빔) | 진폭 % | 펼친 깊이 mm |

축 값이 `null` 이면 그 방향 전체. 저장한 기록: C-scan = 스캔 범위 × 찍은 빔 범위(빔을 모르는 엑셀 기록은 시작·끝 세로선만 — 영상을 칠하지 않음), S-scan = 지금 칸이 기록 범위 안일 때 찍은 레그의 영역(점이 없으면 1·2레그 흐린 점선) + 그 칸에서 찍은 점. 검토 구간 = C-scan 끝 빔 두 줄 띠(검토 완료 회색·품질 불량 보라 점선·기준 미만 황토 점선), B-scan 시작·끝 세로선. 장면 미리보기 = C-scan 첫 빔 줄 띠(양성·약한 양성·무시·음성). 같은 내용이면 같은 객체를 넘겨야 다시 그리지 않습니다.
